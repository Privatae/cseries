# Words a person SAVES are kept as the turn keeps a message, through server/secret_cut.py: every hard secret shape cut to its [REDACTED:<id>] marker before a row keeps the words and before anything embeds them. Each saving route runs for real on the kernel's schema; only the Host's embedding endpoint is a fake that records what it is handed. A made-up key is planted at each route and is never kept or embedded: a memory edit (POST /api/brain/manage/memories/{id}/edit: the new version and its embedding call; re-typing a key into a memory that holds it cut changes nothing), a project's name and description (PUT /api/projects/{id}: the row, and the project search's refresh that embeds them), and a rule rewritten in Training Memory's review (PATCH /api/training-memory/jobs/{id}/review/{pair_id}: the review state, the commit's embedding call and the stored rule). Words with no hard shape (a soft assignment, a random-looking token, a hash) are kept and embedded exactly as typed, an update that sends no name or description leaves both alone, and an upload stays whole (a text file dropped on Documents, a document staged by import, and a document promoted into memory keep the key).
