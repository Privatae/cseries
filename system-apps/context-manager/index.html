Storage

Every piece of your context, and the machine that holds its bytes. platform = kept for you on the network; an S3 bucket or a bastion = a machine you own. A bastion-held piece shows offline when its machine isn't checked in.

Where new context goes. A default covers everything; routes send specific paths to specific machines (a longer prefix wins). Changing placement only affects new writes — what's already stored keeps the machine it was written to.

Host-wide default

Where context lands when no route matches.

Routes — path prefix → machine

Send a specific slice of context to a specific machine. The longest matching prefix wins; anything unmatched uses the default above.

Your machines — choosable context stores

Bastions you run that are online and advertise context storage. These are the machines a route or the default can target.

Folders on machines you run and buckets you own, networked for your host. Your files stay where they are — Privatae Host keeps only the index (a route map of what exists and where), content is read on demand from stores you approve, and every read is logged for you. A folder's index is locations only; a bucket you file things in gets locations + previews. Approving a store always takes your code. There is no delete here — your host structurally cannot remove your files.

Stores

How redundantly your context is kept. Single = one copy on one machine. Replicate = the bytes are fanned out to more machines you run, so a read survives one going offline. Replication applies to bastion-held context (an S3 bucket is already durable on its own).

Embedding is what makes your context searchable by meaning. This covers the context you've brought in (your intake corpus). Embed unembedded pieces, or re-embed everything after changing your model.

Embedding model — where it computes

The model your context is embedded with. Managed runs on the platform; or serve it on a bastion you run (your GPU) — the sovereign lane. Switching lanes keeps your model and existing vectors — nothing is re-embedded.
