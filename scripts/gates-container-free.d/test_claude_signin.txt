# Sign in with your Claude account, run by the Host itself (server/network/claude_signin.py, the Orchestrator's pop-up): a stand-in for Anthropic's `claude auth login --claudeai` prints a link and accepts one code; the link comes back and the binary waits; its environment is the wrapper's allowlist (no token, no API key, no DB names), in a 0700 directory of its own; a refused code saves nothing; the accepted one is kept where the Host keeps its Claude sign-in (the disconnect marker lifted first, the file, the sealed harness:claude_oauth); one sign-in at a time, ended by cancel or by its own clock; only the Orchestrator app may start one. No network, no DB, no container, no SDK.
