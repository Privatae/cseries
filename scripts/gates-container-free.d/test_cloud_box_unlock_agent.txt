# 2026-10-23 (C-Series Cloud, the customer holds the disk key): the unlock agent, on the stand-in cryptsetup. Enrolling needs the setup code and an open, unclaimed vault, and answers the recovery key once; confirming needs that key and starts the claim in a unit nothing stops; a wrong key is refused and recorded, on the plain disk with the source's /24 or /48 only and bounded; the right one opens the Host's ports and starts its services; five tries a minute per source; key changes need a key; a claim cut off after the bootstrap key went is finished by an unlock with a customer key; JSON over a real unix socket. No device, no root.
