# Every door that reads a person's words, or a message a connector or an outside client sends, before the turn does cuts their secret shapes first through server/secret_cut.py, as runtime/session.send_message cuts a message. Each door runs for real on the kernel's schema; only the endpoints are fakes that record what they are handed (the Host's embedding dialer, the media text tower, the code index's embed and rerank, the chat model the pick and the factory planner dial). A made-up key is planted at each door and never reaches the endpoint behind it: the Start dialog's search (POST /api/projects/search) and the project it makes from what was typed (POST /api/projects: no key in the row, none in the refresh that embeds it), the Context Manager's search, the Memory app's two searches, the one index (POST /api/search), code search, a connector message's pick, a /new thread's title and the next pick that lists it, and the Synaptive MCP's shape, recall and signal (and the rows it keeps). Words with no hard shape (a soft assignment, a random-looking token, a hash) reach each endpoint exactly as typed, the Start dialog answers them as it did before (4b24b79b8, field for field), and a search with a key pasted in finds what the same words find without it. The helper: the turn's own markers, soft shapes left, a failing screen leaves the words and logs. Fresh clone of the kernel schema on TEST_PG_DSN / PEER_TEST_DSN / TEST_DSN, else a docker throwaway.
