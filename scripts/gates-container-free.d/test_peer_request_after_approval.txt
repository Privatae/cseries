# A connection request right after the anchor approves a pairing. The anchor's latest beat from the machine predates the approval and still reports the Host pending; the box beats every 60 s and an approval triggers no beat, so POST /api/contacts/request-peer refused "that host is not on a machine you share" for up to a minute. Drives the approval through pairing_grants.sign_and_push_grant and the revoke through pairing_grants.revoke_pairing (the box's answer, the signing key and the audit row stubbed) and the request through the real route: accepted inside the window once the box has confirmed the grant; refused for an unconfirmed, expired, revoked or other-machine grant, a confirmation older than the latest beat, a pairing the box reports revoked or no longer names, and one this Host removed after the beat; each refusal names its reason. Fresh clone of the kernel schema on TEST_PG_DSN / PEER_TEST_DSN / TEST_DSN, else a docker throwaway.
