# 2026-10-19 (the free public App Store): a standalone Host reads the signed public catalog (kind cseries-store, the two release keys verify.js pins) and refuses a tampered, wrong-kind, wrong-key, unsigned, malformed or older catalog and a bundle whose bytes are not the signed sha256; lists, serves bundles in slices, the icon and a free entitlement; the App Store router uses the network's door when it answers and the public store when it does not, never routing around a door for an app outside the catalog; and the install route installs a public app end to end through installer.install_bundle. In-process, against a loopback HTTP server on an ephemeral port; no container. 2026-10-20: the signed issued_at is read; a catalog older than 45 days, an undated one and a rollback record that cannot be kept each list with a notice and still install. 2026-10-21: at a standalone Host's first start the boot pass (default_install.run_loop, now started from server/main.py) installs the app the catalog marks default, once; an uninstall holds. The start-time upgrade never installs a runtime app's version that reserves more memory than the installed one (an over-plan refusal would uninstall it); that one waits for the person.
