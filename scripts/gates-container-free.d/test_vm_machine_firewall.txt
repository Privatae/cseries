# 2026-10-22 (C-Series VM guest): the machine wall (vm/wsl/rootfs/etc/cseries-machine/machine.nft and its loader, in the WSL and Lima guests) keeps every container in the guest off the machine under the VM. Text: its own table replaced whole, established first, DNS to the resolvers before the drop; both images enable it. Loader: adds the default gateway, the resolvers and the addresses file, skips a line that is not an address, and nft -c takes the result. As root, real packets in private network namespaces playing Lima's user-mode network, a podman bridge and a container: without the wall the container reaches 192.168.5.2:22; with it 192.168.5.2:22/7877/7878/7978/8800 and the machine's LAN address are dropped, 192.168.5.3 answers on 53 only, a LAN model server and the internet still answer, a forwarded port from the machine still reaches the container, the proxy's uid 13 is walled and the guest's root is not, twice. Skips the load and packet checks without nft, ip, unshare or root unless CSERIES_REQUIRE_NFT=1.
