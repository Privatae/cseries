# image_baked_apps.txt — THE single source of the image-baked app set.
#
# One app id per line; '#' comments and blank lines ignored. Sorted.
#
# Consumers (all read this file — none holds its own copy any more):
#   scripts/rebuild_factory_bundles.sh   packs these into /app/native-bundles/
#   scripts/smoke_test.sh                pins the baked set in the image gate
#   scripts/test_store_version_bump.py   skips these in the store-lane ratchet
# The platform DB mirrors the catalog-facing half as
# app_store_apps.distribution='image' (a platform-side migration); the
# store-delisted ratchet flags drift between the two.
#
# Being here means: the app's .cseries bundle ships inside the entity image
# and reaches every Host at boot (category-2 ids gate actual install via
# the manifest's target_entities). It does NOT mean kernel-required —
# that is server/applications/kernel.py::KERNEL_REQUIRED_APPS (3 ids),
# a deliberately different, smaller set.
#
