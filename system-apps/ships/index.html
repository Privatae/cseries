Ships
one plan, one tap, every step signed

Pipelines

Each pipeline is a file at ships/<name>/pipeline.yaml beside the ops it runs. Run builds one plan for the whole ship and sends it to your approval device; nothing reaches a machine until you approve it there.

Machines

Every machine a pipeline names. A machine takes a ship step when its bastion runs action ops (0.46.0 or later), your approval device is pinned there, and a grant with purpose ship covers it.

Keys

The credentials each step's op declares, by name, and whether your Host's vault holds them. A step is sealed its credentials for that one run, to that one machine; the values never show here.
