# The forge CI queue: one run per PR. check.yml cancels a PR's run still going when a push, merge or close arrives (concurrency group per PR, cancel-in-progress, `closed` in the triggers), and its first job, `current`, skips every check when the PR merged, closed or moved on. Runs `current`'s own decision code on open/merged/closed/newer-head PRs and the whole step on a fake curl (a skip also needs a complete list of open PRs naming no other PR at this commit, since check results belong to the commit), pins that the checks run unless skip == 'true' (so a forge that cannot be asked runs them), and runs cleanup's script on a fake docker: a cancelled run's images go (this PR's, and any CI image over 6 h old), a younger one stays, never -f; and every image the build and cleanup remove is picked by this repository's own label or image name, since the runner's Docker is shared with other repositories' CI. Pure YAML + Python.
