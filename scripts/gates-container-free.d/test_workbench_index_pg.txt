# The Workbench Index's server half on a real kernel schema holding test_project_list_speed_pg's Host (300 projects, 100,000 turn rows). POST /api/projects/index lists archived pages marked, lets a page's conversation lift it (BM25 over its turn rows) while a page named for the text stays first, also where rank fusion of the same arms would not and where the name holds the text only inside a word; keeps the Start dialog's order where no conversation matches, also with an embedding model (scored by pgvector in the read); marks the matched words in an excerpt from where it matched; names and leaves out words too common to tell pages apart; never lists another entity's rows or an artifact. The Start dialog's search answers exactly as main's (8b3cb482c) with and without an embedding model. The conversation read goes through the GIN index under a Limit (custom and generic plans, after ANALYZE) and reads at most CONV_ROWS rows; a 1 s wall-clock backstop. POST /api/workbench/index/send: the pick's list is the first 12 pages of the Index's own search for the message (open and archived, turnless and ticket ones too) and the open page, marked and kept, each page's last exchange read through v216's indexes (a few rows a page, never every row); the pick's input stays within a fixed budget at 50 pages and at 300 (it was ~8,400 and ~48,700 tokens listing every page) and a page ranked below the first 12 cannot be picked; one call, one tool, pick_page, in the Index's words; a pasted key is cut before the search embeds the words, before the pick's call, before a new page takes its title from them and before the turn; the marker "Index message, picked this page: <reason>" on the page, never a page's last exchange; a "new" pick makes a project and a failed marker leaves none; an archived pick is restored in the marker's transaction (a failed marker leaves it archived), a refused restore is a 409 with nothing written; a failed pick starts nothing and returns the pages the Host was shown; the turn starts through brain_service.send_message on the project's thread key; the route is walled from the Host (kernel_ops). Scripted model and turn body; fresh clone of the kernel schema on TEST_PG_DSN / PEER_TEST_DSN / TEST_DSN, else a docker throwaway.
