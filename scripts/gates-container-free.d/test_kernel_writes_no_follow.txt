# SECURITY: no kernel writer into a project folder writes through a link. server/replace_file.py opens each folder below the caller's root with O_NOFOLLOW, writes a new file and renames it over the name, and refuses a name or folder that is a link; set_project_manifest_service (app.yaml), review._snapshot_to_project (a build's land) and artifacts._write_new_inode (write, promote, import) all use it. A hard link elsewhere keeps its bytes, a link as the name or on the way is refused with its target untouched, a file's mode is kept (rwx bits only, never a set-user-ID bit), and the path is read as pathlib reads it, as every caller's own checks do: a backslash is part of a name, so `.git\config` is never written into .git/config, and `./index.html` is index.html. Temp folders and a stub pool; no DB, no network.
