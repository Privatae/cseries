# afterwards and an unchanged roster is never re-sent. Plus: only entity ids
# leave the pod (asserted on the signed terms' exact field set — no names, no
# verify keys, no roles); the terms bind app AND group, so a signature lifted
# from one app cannot apply to another; signing through the production path
# with every field mutated; a publisher may only gate an app on a roster it
# OWNS; and the publish_app schema and its executor agreeing on the three
# audience values, because a schema the executor rejects is a tool the model
# can call and the code always refuses.
