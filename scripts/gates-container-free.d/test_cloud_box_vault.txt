# 2026-10-23 (C-Series Cloud, the customer holds the disk key): the vault, on a stand-in for cryptsetup that behaves as Debian 13's was measured to. HKDF is RFC 5869's; a passkey's passphrase and a recovery key have their fixed forms; the bootstrap key opens the vault at boot only before the claim; the claim adds the customer's keys, then kills the bootstrap slot and its file, then re-encrypts with the customer's keys only (both kept), so the bootstrap key never wraps the new volume key; a reset mid-re-encryption leaves it locked and an unlock with either customer key resumes it; unlocking, key changes; no key on any command line. No device, no root.
